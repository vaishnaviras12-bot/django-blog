# Django Blog

A blog application built while following Corey Schafer's Django tutorial series. This project is for learning Django fundamentals, including models, views, templates, authentication, and CRUD operations.

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Features

- User registration and login
- Create, edit, and delete blog posts
- User profiles
- Pagination
- Password reset
- Responsive interface

## Acknowledgements

This project is based on the Django tutorial series by Corey Schafer and is intended for educational purposes.
